# Nest a Nook

Website for **Nest a Nook Gifts and Stationery WLL** (CR No. 256542), Qatar — nestanook.qa

Static site: `index.html` + `images/`. Pages (Home, Shop, product pages, About Us, Contact, Terms, Privacy, Return & Refund, Shipping) are hash-routed in one file. Product enquiries open WhatsApp (+974 3118 4426).

Deploy by uploading the files to any static host (Hostinger, GitHub Pages, Netlify).
